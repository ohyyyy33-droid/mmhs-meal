# 면목고 오늘의 급식 🍱

QR을 찍으면 바로 열리는 면목고등학교 급식 웹앱입니다.

- 요일별 메뉴 (월~금, 주 단위 이동)
- 칼로리 · 탄수화물/단백질/지방
- 메뉴마다 알레르기 유발 재료 표시
- "내 알레르기" 설정 시 해당 메뉴를 주황색으로 강조 (각자 폰에만 저장)

## 페이지
- `index.html` — 급식 앱 (학생용 주소)
- `qr.html` — 인쇄용 QR 안내문 (앱 주소로 QR을 자동 생성)

## 데이터
교육청 NEIS 공개 API(서울 B10 / 면목고 7010077)에서 실시간으로 불러옵니다.
접속이 안 될 때를 대비해 GitHub Actions가 매일 새벽 `meals.json`을 갱신합니다.
(선택) NEIS 인증키를 받으면 저장소 Settings → Secrets → `NEIS_KEY`로 등록하세요.
